## Key Concepts I Learned

<!-- Write the main ideas covered in today's session -->


- Learned about fundamental Azure storage account types  and data redundancy options, and when to use which option. I also explored data migration tools like AzCopy, Azure Storage Explorer, Azure Data Box, and Azure Sync.

- Learned about account-level security configurations including requiring secure transfer (HTTPS only), setting minimum TLS version to 1.2, disabling public/anonymous blob access, and blocking cross-tenant object replication. I understood different authentication mechanisms like Microsoft Entra ID (RBAC), Shared Key/Storage Account Keys, Shared Access Signatures (SAS), and Stored Access Policies.

- I covered secure network perimeters using Virtual Network (VNet) service endpoints, storage firewalls (IP rules), Resource Instance rules, and Private Endpoints (Private Link).
